# Design reference (v2)

Static mockups for Price My New Roof. Open in a browser; no build step.

- `landing.html`: landing page (desktop, responsive)
- `estimate.html`: roof and estimate page (desktop, responsive)
- `phone-estimate.html`: estimate page at phone width (390px)

Bracketed values like `[$XX,XXX]` are placeholders for computed data.
The satellite image is a drawn stand-in; production uses the Google Maps satellite view.
Tokens, components and rules live in the Design section of `docs/SPEC.md`, which wins if anything here disagrees.
